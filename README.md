### About Me

I am a Full-Stack Developer and Systems/Tooling Engineer designing privacy-first browser architectures, AST deobfuscators, and high-performance Web utilities. My engineering work is grounded in **100% client-side computation**, perceptually uniform color science (OKLCH), zero-layout-shift interfaces, and sub-millisecond execution.

Official developer portfolio and interactive project hub: **[oathanrex.github.io](https://oathanrex.github.io)**

## Architectural Principles & Standards

- **100% Client-Side Privacy**: All utility tools, transformations, deobfuscators, and encoders execute entirely within the user's browser runtime. Zero tracking, zero telemetry bloat, and zero server round-trips for user data.
- **Perceptually Uniform OKLCH Design System**: Hardware-accelerated color systems providing mathematically balanced contrast across OLED True-Dark and Paper-Light themes.
- **Zero-Layout-Shift (CLS 0.00)**: Strict code-splitting paired with pixel-precise reserve shells to eliminate rendering jitter.
- **Universal Accessibility (WCAG AA+)**: Universal keyboard shortcuts (`Ctrl+Enter`, `Ctrl+K`), ARIA landmark compliance, and responsive execution across all viewports.
